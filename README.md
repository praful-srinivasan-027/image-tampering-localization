# Image Tampering Localization

A PyTorch implementation of U-Net for image tampering localization using the CASIA dataset.

## Features

- Custom PyTorch `Dataset` and `DataLoader`
- U-Net implementation from scratch
- Image preprocessing with OpenCV
- Binary segmentation for tampered region detection

## Dataset

- CASIA Image Tampering Detection Dataset

## Tech Stack

- Python
- PyTorch
- OpenCV
- NumPy
